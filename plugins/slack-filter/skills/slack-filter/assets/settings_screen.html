Slackフィルタの設定画面。除外する人、拾う発言と話題、読むチャンネル、結果の形、次に設定画面を開くタイミングを選び、設定を記録するボタンでClaudeに送る。

1. 除外する人を決める

名前を入れて「追加」を押してください。ここで除外した人の発言は、2. の話題の候補づくりにも使いません。

2. 拾う発言を選ぶ

チェックを入れたものを集めます。1つ以上選んでください。

直近1週間の、自分の発言と自分がいるスレッドから、Claude が話題をまとめました。関係あるものを選んでください。（数字は、もとにした発言の件数）

足りない話題があれば、書いて「追加」を押してください。

3. 読むチャンネルを決める

チャンネル名をカンマ区切りで入力します。空欄なら、自分が参加しているチャンネルをすべて読みます。

4. 結果の形を選ぶ

5. 次にこの画面を開くタイミングを選ぶ

選んだタイミングのあと、最初に skill を使ったときに、この画面がもう一度開きます。開いたときは、今回の設定が入った状態から始まり、話題の候補はその時点の直近1週間で作り直します。

この黄色いボタンを押すと、上の内容が Claude に送られて保存されます。
