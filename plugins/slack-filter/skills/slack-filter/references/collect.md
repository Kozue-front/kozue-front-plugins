# Slack から集める手順

Slack のコネクタ(検索・チャンネル読み取り・スレッド読み取り)を使う。ツールの名前は環境で違うので、役割で探す。

- 検索:キーワードと、`from:` `in:` `after:` などの絞り込みで発言を探すツール
- スレッド読み取り:親の発言と返信をまとめて読むツール
- ユーザー検索:名前からユーザーIDを探すツール

## 拾う対象ごとの集め方

期間の始まりを `after:YYYY-MM-DD` に入れる。日付単位でしか絞れないので、取ったあとに発言の時刻で期間の外を捨てる。チャンネルが決まっていれば `in:<#ID>` を足す(複数なら繰り返す。同じ絞り込みの繰り返しは「または」になる)。

### 1. 自分宛てのメンション

- 検索の言葉に自分へのメンション(`<@自分のID>`)を入れて探す(実際の Slack で、この方法で自分宛ての発言が取れることを確認済み)
- 本文の中のメンションは `<@U0123ABCD|表示名>` の形で返る。外したアカウントへのメンションも、この形のIDで判定する

### 2. 自分へのDM

- `is:dm` の絞り込みで、期間内に自分が受け取ったDMを探す。チャンネルの設定にかかわらず見る
- `is:dm` が効かない環境では、検索のDMの種類の指定(`channel_types` に `im` を指定するなど)で絞る。それもできなければ「DMは見ていません」と結果の冒頭に書く
- 外したアカウントからのDMは、ブロックなら捨て、場面ごとなら①(自分宛て)として扱う

### 3. 自分がいるスレッド

- `from:<@自分のID>` で期間内の自分の発言を探し、スレッドの中の発言なら、そのスレッドを読む
- スレッドを読むときは、期間内の返信だけを拾う。期間より前の返信は、話の流れを理解するためにだけ使い、結果には出さない

### 4. 話題

- 設定の話題ごとに、保存した検索の言葉で探す。言葉は1つずつ検索し(全部を一度に入れると「すべてを含む」になり、ほとんど当たらない)、結果をまとめる
- 当たった発言が本当にその話題についてかを、本文で確かめる。言葉が一致しただけの無関係な発言は捨てる

## 発言者のIDを必ず取る

外す判定はユーザーIDで行う。検索結果の簡易表示(concise)では、発言者が表示名でしか返らないことがある。発言者のIDが結果に無いときは、詳細表示(detailed)で取り直す。それでもIDが取れない発言は、表示名が外したアカウントの保存済みの表示名と一致すれば外す側に倒す。

## ボットや自動通知

検索では、ボットの発言も取る(取らないと件数が数えられないため)。そのうえで、設定の `pick.bots` が `false` なら結果に入れず、ボットごとの件数だけを数える。ボットかどうかは、検索結果のボットの印や、発言者がアプリであることから判断する。

## 量が多いとき

検索は1回に20件までしか返らない。続きがあれば次のページを取る。1つの対象で100件を超えたら、そこで止め、結果の冒頭に「〇〇は件数が多かったため、新しいものから100件だけを見ました」と書く。黙って切らない。

## 外す処理は、集めた直後に行う

集めた発言は、まとめる前に必ず SKILL.md の「外したアカウントの扱い」を通す。スレッドを読んだ場合は、スレッドの親と返信の1件ずつに当てる。
